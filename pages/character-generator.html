output — take the sheet with you

plain text is for pasting into a chat window. the pdf is written here rather than filled in, so it is this machine’s sheet and not the official form. the json is every number on the sheet, for anything that would rather read it than look at it.

input — patch a channel

one dial per channel. turning it walks that channel’s seed forward, turning it back brings the last one straight back — the dial is its own undo, so it keeps no takes. a dialled channel holds until you release it below.
